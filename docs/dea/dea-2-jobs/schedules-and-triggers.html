スケジュールとトリガー — 5種類の起動条件

トリガーは特定の条件やスケジュールに基づいてジョブの実行を自動的に開始する規則です。 5種類ありますが、時刻で動く / 出来事で動く / 人が押すの3つに畳めます。

トリガーとは何か便利さではなく、人の介入点を減らすため

トリガーを入れる意味は単なる便利さではありません。人が介入する箇所を減らすことにあります。 人が介入するところには、遅れ・間違い・実行漏れが生まれます。 トリガーを置けば 24 時間動き続け、チームが居るかどうかに関わらず一貫して実行されます。

時刻で動くもの本番ワークフローの背骨

指定の仕方は2通り — 画面から選ぶか、cron 式を書くか。

方法できること
画面から毎時・毎日・毎週・毎月。cron の書き方を知らなくても組める
cron 式「営業時間中だけ15分おき」「毎月の第1月曜日」のような複雑な条件
日次 ETL
毎朝 6 時に前日ぶんを処理
週次レポート
毎週月曜の朝に経営向けダッシュボードを作る
月次集計
毎月1日に月次の指標を計算
保守
ストリーミングジョブの定期的なチェックポイント

タイムゾーン

必ず業務の文脈に合わせて指定すること。 複数の地域にまたがる組織では、ここがずれると事故になります。

出来事で動くものファイル到着とテーブル更新

File Arrival トリガー

指定したストレージに新しいファイルが検出されると動きます。 対応は AWS S3 / Azure Storage / GCP GS / Databricks Volumes。 効くのはデータの到着が不規則なときです — パートナーからのデータ提供、IoT のセンサーデータ、取引データ、各システムのログ。 いつ来るか分からないものを時刻で待ち構えるのは無駄が多い。

ファイル名のパターンを指定できるので、関係ないファイルや書き込み途中の一時ファイルを無視できます。

Table Update トリガー

指定したテーブルが更新されたときに動きます。監視するのは挿入・更新・削除・マージ。 狙いははっきりしていて、時刻ベースのスケジュールを置き換えることです。 新しいデータが着いたらすぐ動くので鮮度が上がり、何も変わっていないのに毎朝動く、がなくなります。

段設定中身
1トリガーの種類Table update を選ぶ
2監視するテーブル1トリガーにつき最大10テーブル。UC 管理の Delta / Iceberg / 外部 Delta / マテリアライズドビュー / ストリーミングテーブル
3起動の条件いずれかが更新されたら / すべてが更新されてから
4任意トリガー間の最小時間。動きすぎを防ぐ

3段目が要点

複数のソースが揃ってから処理したいなら「すべてが更新されてから」。 どれか1つでも動いたら反応したいなら「いずれか」。ここで挙動が大きく変わります。

常に動くもの、人が押すものContinuous と Manual

Continuous トリガー

前の実行が終わるか失敗するとすぐ次を始めます。つまり常に動き続ける。 再試行の仕組みは Databricks が自動で面倒を見ます。 向いているのはストリーミングのワークロード — リアルタイムダッシュボード、不正検知、IoT の取り込み、変更データキャプチャです。

監視の考え方が他と違う

終わることを前提にしていないので、完了を待つ形の監視は成り立ちません。 他のトリガーと同じ感覚で見ていると異常に気づけません。

Manual トリガー

スケジュールもイベントも持たず、必要なときに動かすもの（設定上は「なし」）。 画面から「Run now」、あるいは「Run now with different settings」でパラメータを上書きして走らせられます。 API・CLI・SDK・Databricks Asset Bundles からも動かせます。

使いどころ
開発と検証 / デバッグ / 過去ぶんの穴埋め / 品質問題を直したあとの再処理 / 急ぎの業務対応 / 自動化を有効にする前の本番確認
あとから組み合わせられる
開発中は手動、固まったらスケジュールという進め方ができる。

どう選ぶか誰が「いつ」を決めるのか
状況選ぶトリガー
時刻が予測でき、決まった周期で回すScheduled
データの到着が不規則で、来たらすぐ処理したいFile Arrival
上流テーブルの更新が起点で、鮮度を上げたいTable Update
止まらずに流れ続けるものを扱うContinuous
開発中、あるいは一度きりの作業Manual

判断の助けになる見方

Scheduled は「いつ動かすか」を自分で決める。イベント系は「いつ動くか」をデータに決めさせる。 後者のほうが鮮度は上がりますが、いつ動くか読めません。 この違いを踏まえて選んでください。
