レイクフローという一枚の絵入れる・変える・回すの3層

Databricks のデータエンジニアリング機能は Lakeflow（レイクフロー）という名前でひとつにまとまっています。 中身は3つで、それぞれ担当する工程が違います。

Lakeflow Connect
入れる。外部からデータを運び込む入口。このコースが扱う範囲。
Spark Declarative Pipelines
変える。取り込んだデータを SQL と Python で宣言的に変換していく層。
Lakeflow Jobs
回す。いつ・どの順で動かすかを決めるオーケストレーションの層。

この3つは共通の土台の上に乗っています。処理エンジンが Apache Spark と Structured Streaming、 ガバナンスが Unity Catalog、ストレージが Delta Lake です。 3層は独立した製品ではなく、同じ土台を共有する役割分担だと捉えると、あとの話がつながります。

なぜ入口を1つにまとめるのかConnect の価値は「無かった頃」と比べて見える

企業のデータは置かれている場所がばらばらです。オンプレミスのファイル、古い基幹システム、 業務データベース、クラウドストレージ、SaaS アプリケーション、リアルタイムのイベントストリーム。 従来はこれらを取り込むのに、接続先ごとに別の道具を使うことになりました。

ばらけた入口が生む3つの問題

運用の手間。道具ごとに監視も障害対応も違う。 ガバナンスの不揃い。誰がどのデータを取り込んだのかを一箇所で見られない。 可観測性の分断。止まったとき、どこで止まったのかを追うのに複数の画面を行き来する。

Lakeflow Connect は、この入口を Databricks の中に寄せます。設定も保守も同じ場所で行い、 オーケストレーションと可観測性とガバナンスが最初から揃った状態になる。 新しい取り込み技術というより、ばらけていた入口を1つの面にまとめる層です。

コネクタは3つの入口に分かれる性質で覚える。試験でも実務でも効く

Lakeflow Connect が用意している入口は3種類です。相手が何かで決まります。

入口相手使える取り込み方式特徴
ファイルのアップロード 手元のローカルファイル — ボリュームに上げる、ファイルから直接テーブルを作る。少量・一度きり
Standard Connectors クラウドオブジェクトストレージ、Kafka、その他 バッチ / 増分バッチ / ストリーミング いちばんよく使う。カスタマイズの余地が大きい
Managed Connectors SaaS アプリケーション、業務データベース 増分の読み書き 認証・変更データの取得・例外処理をコネクタが持つ。自由度は下がる

判断の置き方

ファイルとして置かれるものは Standard。 アプリやデータベースに接続して取りにいくものは Managed。 手で持ち込むだけならアップロード。 Standard と Managed の違いは、突き詰めると自由度と手間のトレードオフです。

取り込み方式は3つ違いは「前回どこまで読んだかを覚えているか」

Standard Connectors を使うとき、取り込みの方式を選びます。

方式何をするかSQLPython / パイプライン
バッチ 行のかたまりをまとめて読む。動くたびに全レコードを処理し直す CREATE TABLE AS SELECT spark.read.load()
増分バッチ 新しいデータだけを読み、既読のレコードは自動で飛ばす COPY INTO Auto Loader（タイマー起動）
CREATE OR REFRESH STREAMING TABLE
ストリーミング 生成されたそばから連続的に読む。実体はごく短い間隔のマイクロバッチ — Auto Loader（連続トリガー）
宣言的パイプラインの連続モード

この3分類はコースの整理の仕方です。 Databricks の公式ドキュメントは「バッチ / 増分バッチ / ストリーミング」という章立てを取っていません。 用語そのものより、上の図が示す区別のほうを持ち帰ってください。

デルタテーブルとメダリオン着地先の構造。性質はすべてログから出る

取り込んだデータは Delta Lake に Delta テーブルとして着地します。 中身は2階建てです。データそのものは Parquet 形式のファイルとしてフォルダに並び、 そこに Delta ログという JSON 形式の記録が並走します。 どのファイルがいまのテーブルを構成しているのかを、このログが持っています。

その Delta テーブルを品質の段階で三層に分けるのがメダリオンアーキテクチャです。 ブロンズが生のまま、シルバーが整えたもの、ゴールドが使う形にまとめたもの。 取り込みが着地するのはブロンズです。

この回の持ち帰り

外部のソースがある → Lakeflow Connect が入口になる → 方式を選んで運ぶ → 着地先は Delta テーブルで、メダリオンのブロンズにあたる。 ここまでが一本につながっていることが、この回で押さえる全部です。
