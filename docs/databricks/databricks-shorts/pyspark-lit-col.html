lit() と col() の違い

固定値を Spark の列として渡したいとき、そのままでは PySpark に伝わりません。 lit() は Python の普通の値を Spark の Column に変換する関数です。

固定値を列として渡す lit()literal

lit は literal（固定値）を Spark の Column に変換する関数です。 withColumn() の第2引数には Python の値ではなく、Spark の Column 式を渡す必要があります。

from pyspark.sql.functions import lit

df.withColumn("source", lit("web"))
idnamesource
1Tanakaweb
2Suzukiweb
3Satoweb

withColumn 自体の使い方（列の追加・上書き・cast）は PySpark の列操作で扱っています。ここでは lit と col の2つに絞ります。

lit() を付けないとどうなるか不正な例

 
# × 不正: ただの Python 文字列
df.withColumn("source", "web")

# ○ 正しい: lit で Column に変換
df.withColumn("source", lit("web"))

"web" と lit("web") は別物

"web" はただの Python の文字列で、Column 式ではありません。 lit("web") にして初めて、Spark の Column 式として渡せます。

数値でも真偽値でも使えるlit(0.1) / lit(True)

lit は文字列に限らず、数値や真偽値にも使えます。型が変わっても、 固定値を Column に変換するという役割は同じです。

df.withColumn("tax_rate", lit(0.1))
df.withColumn("active", lit(True))

col() との対比既存列 vs 固定値

col() と lit() はセットで覚えると分かりやすいです。 col() は既存の列を参照し、lit() は固定値を列として扱います。

from pyspark.sql.functions import col, lit

df.withColumn(
    "discount_price",
    col("price") - lit(20)
)
関数対象例
col()既存列を参照col("price")
lit()固定値を列として扱うlit(20)

数字の流れで見ると違いがはっきりします。col("price") は行ごとに違う値を取り、 lit(20) はどの行でも 20です。その2つを引き算した結果が discount_price になります。

idnameprice値引き額discount_price
1Tanaka12020100
2Suzuki802060
3Sato25020230

「値引き額」の列は lit(20) を可視化するために並べたもので、実際の DataFrame には作られません。 計算の途中で全行に 20 が配られている、というイメージです。

覚え方と例外すべてに lit が要るわけではない

断定しすぎない

col("price") * 1.1 のような単純な演算では、PySpark が数値を自動的に リテラルとして扱うこともあります。すべての固定値に必ず lit() が必要というわけではありません。

覚え方

col() = 既存列を使う。lit() = 固定値を列として使う。 ただし、withColumn() に固定値そのものを渡すときは、lit() を使うと明確です。
