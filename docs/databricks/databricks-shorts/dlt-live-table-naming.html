LIVE TABLEの意味と名前の変遷

LIVE TABLE の LIVE は「リアルタイム」という意味ではありません。 旧 DLT における「パイプラインによって定義・管理されるテーブル」という製品用語です。 現在は Materialized View / Streaming Table という、 処理の意味が分かる名称へ整理されています。

LIVEはリアルタイムではないまず結論

よくある誤解

LIVE を「常にリアルタイム更新される」と読むと混乱します。正しくは 「DLT パイプラインの管理下にある」という意味です。

用語何を指すか
通常の TABLE通常の Delta テーブル。パイプライン専用の概念ではない
旧 LIVE TABLEDLT パイプラインが管理するテーブル
旧 STREAMING LIVE TABLEDLT パイプラインが管理するストリーミングテーブル

なぜLIVEだったのか管理下という印

古い DLT の問題では CREATE LIVE TABLE customers AS ... や CREATE STREAMING LIVE TABLE orders AS ... がよく出てきます。LIVE TABLE は必ずしもストリーミングではありません。ストリーミングかどうかは、別途 STREAMING が付いているかで区別していました。

書き方扱うもの
LIVE TABLEバッチ / 全体状態を扱う系
STREAMING LIVE TABLE増分・ストリーミング系

旧Delta Live Tables製品名が用語に出ていた

以前は製品自体が Delta Live Tables（DLT） と呼ばれていました。そのため LIVE TABLE / STREAMING LIVE TABLE という言葉が前面に出ていました。

旧 Python API抜粋

import dlt

つまり製品名がそのまま SQL の用語に出ていた時期です。名前の由来はここにあります。

現在のLakeflow pipelines名前が整理された

DLT という製品名は整理され、Databricks のパイプライン機能は Lakeflow pipelines（Lakeflow Spark Declarative Pipelines）として扱われています。

現在の Python API抜粋

from pyspark import pipelines as dp

旧 dlt API は互換性のため残っていますが、新しい名前への移行が推奨されています。

テーブル名称の対応旧 → 現在

現在のSQL直感的になった

Streaming Table / Materialized View現在の書き方

CREATE OR REFRESH STREAMING TABLE orders
AS SELECT * FROM STREAM source_orders;

CREATE OR REFRESH MATERIALIZED VIEW daily_sales
AS SELECT store_id, SUM(amount) FROM sales GROUP BY store_id;

STREAMING TABLE は作る側、STREAM(...) は読む側。Materialized View のほうは、集計や全体状態を反映した結果を保持する用途に向いています。

LIVEスキーマもレガシー仮想スキーマの名残

古い DLT のコードでは LIVE.customers のような書き方も出てきます。これは旧 DLT の LIVE 仮想スキーマの名残です。現在の新しいパイプラインではレガシー扱いで、新しい公開モデルでは基本的に使わない方向になっています。

古い試験問題で FROM STREAM(LIVE.customers) が出てきても慌てないこと。LIVE = 旧 DLT のパイプライン内参照、と理解すれば十分です。

普通のテーブルは今もある2本立て

Lakeflow の用語があるからといって、通常の Delta テーブルがなくなったわけではありません。CREATE TABLE customers (customer_id BIGINT, name STRING) USING DELTA; は普通の Delta テーブルです。

試験向けの覚え方両方覚える

古い試験問題では、まだ旧名称が出てくる可能性があります。旧用語と現在の感覚を、両方セットで覚えます。

旧 DLT 用語現在の読み替え
LIVE TABLE
パイプライン管理のバッチ / 全体状態系		Materialized View
集計・変換結果を現在状態に合わせて維持
STREAMING LIVE TABLE
パイプライン管理の増分処理系		Streaming Table
新しく届いたデータを増分処理

LIVE は「リアルタイム」ではなく、旧 DLT における「パイプライン管理下」という製品用語。
