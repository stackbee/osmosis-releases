Managed Table / External Table / Volume

違いは一言でいうと、Unity Catalog がデータファイルの保存場所とライフサイクルまで管理するかです。 DEA 対策としては、どちらを選ぶか・DROP したとき何が起きるか・Volume は何のためにあるか、の三点に絞ります。

三つを分けるのは管理の範囲一言でいうと

Managed Table、External Table、Volume。名前が並んでいるだけだと区別がつきにくいところですが、 分かれ目は「Unity Catalog の管理がどこまで及ぶか」の一点です。

Managed Table
保存場所もライフサイクルも Unity Catalog が管理する
External Table
保存場所は利用者側。Unity Catalog はテーブル定義・権限・監査・Lineage を管理する
Volume
Table として扱うのではなくファイルそのものを扱う場所。こちらにも Managed / External がある

この回の位置づけ

ep008「ガバナンスとセキュリティ」では DROP TABLE したら実データはどうなるか、という判別の一文までを扱いました。 ここではその先——どちらを選ぶか / 削除したとき何が起きるか / Volume は何のためにあるかに絞ります。

Managed Table住所も片付けも任せる

Unity Catalog が保存場所を決め、データファイルのライフサイクルも管理します。 作り方は素直で、テーブル名と列を並べるだけです。

CREATE TABLE sales.orders (...)

保存先を自分で細かく指定しなくても、Unity Catalog の Managed Storage 配下に置かれます。

特徴意味
保存場所を Unity Catalog が管理LOCATION を書かない
DROP TABLE で基盤データも削除メタデータだけでなく実データも消える
基本的に推奨されるテーブル種別迷ったらこちら、という位置づけ

External Table住所は自分で持つ

データファイルは自分たちが管理するクラウドストレージ上にあります。 LOCATION の一行があるかどうかが分かれ目です。

CREATE TABLE sales.orders USING DELTA
LOCATION 's3://company-data/orders/';
特徴意味
保存場所を利用者側が指定バケットの下のパスを LOCATION に書く
Unity Catalog はアクセス制御・監査・Lineage を管理持つのはテーブル定義と権限まで
DROP TABLE しても元のデータファイルは残る登録を外すだけ。ファイルはストレージにそのまま

分担はこうなります。Unity Catalog が管理するのはテーブル定義・権限など。 S3 / ADLS / GCS 上の実データは利用者側が管理します。

DROP したときの分かれ道ここがいちばん問われる

Volume は何のためにあるかこの回の主役

Volume は、Table として扱うより「ファイルそのもの」を扱いたいときに使います。 行と列に落とし込む前の、ファイルのままのものが対象です。

置くもの典型例
半構造化・テキストJSON / CSV
非構造化PDF / 画像
成果物・依存物モデルファイル / Python wheel

アクセスは /Volumes という入口の下に、カタログ・スキーマ・Volume 名と続くパスで指します。 テーブル名の代わりにパスで呼ぶ形です。

/Volumes/main/raw/files/sample.json

Volume にも Managed / External があります。考え方は Table とまったく同じで、 保存場所を Unity Catalog に任せるか、自分で持つかの違いです。

Table と Volume の感覚扱いたい形が違うだけ

三つのケースで選ぶ具体例
ケース状況答え
1Databricks 中心で新規 DWH を作るManaged Table が自然
2既存 S3 上の Delta データを消さずに Databricks から管理したいExternal Table
3Auto Loader が読む CSV の置き場を Unity Catalog 配下で管理したいVolume を使うケースがある

問題文はたいてい、この三つのどれかの形で出てきます。状況の側から引けるようにしておくのが実戦的です。

試験ポイントと覚え方逆引きと覚え方
問題文にこう書いてあれば答え
「DROP したとき元データを残したい」External を疑う
「ストレージのライフサイクルまで Databricks 側に任せたい」Managed
「非表形式ファイルを扱う」Volume

覚え方。Managed = Unity Catalog が住所も片付けも管理
External = 住所は自分で持つ、Unity Catalog は受付・権限管理
住所と片付け。この二語で、いまどちらの話をしているかが決まります。
