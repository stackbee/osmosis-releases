# podcast-releases

ポッドキャストの**配信面**です。音声ファイルとRSSフィードを [Releases](../../releases) に置いています。

- 各エピソードの音声 … タグ `<channel>-<episode>` の Release asset
- 各チャンネルのフィード … タグ `feed` の Release asset `<channel>-feed.xml`
- カバー画像 … このリポジトリの `shows/<channel>/cover.jpg`

台本や生成スクリプトは別リポジトリ（private）にあります。ここはコードを持ちません。
